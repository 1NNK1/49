#  Тестирование асинхронной логики (ДЗ 49.1)

Проект демонстрирует создание React-компонента с асинхронной загрузкой данных и написание тестов для проверки всех состояний (загрузка, успех, ошибка).

##  Технологии
- React
- Vite
- Vitest (для тестирования)
- React Testing Library (для рендеринга компонентов в тестах)

##  Описание реализации
1. **UserProfile.jsx**: Выполняет GET-запрос к JSONPlaceholder API. Содержит логику обработки состояний `loading`, `error` и `success`.
2. **UserProfile.test.jsx**: Содержит 3 основных теста:
   - Проверка отображения лоадера.
   - Проверка успешного рендера данных пользователя.
   - Проверка отображения сообщения об ошибке.
   - Используется мокирование `global.fetch` для изоляции тестов от реального сервера.

##  Запуск и тестирование
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите приложение:
   ```bash
   npm run dev
   ```
3. Запустите тесты:
   ```bash
   npm run test
   ```
